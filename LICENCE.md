## 🧩 About

**Civilization 7 Client Menu** is a curated list of Civilization 7 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, turn timer
- **Quality-of-Life Helpers** — city planner, unit manager, overlay notes
- **Research Notes** — strategy layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Resource Tracker — monitor yields and stockpiles live
- Turn Timer — keep track of turn time for study
- Unit Movement Notes — plan paths and actions
- Production Queue Overlay — view city production at a glance

### 🗺️ Map & Info
- Map Overlay — toggle grid and resource icons
- Tile Yields Viewer — see potential yields per tile
- Diplomatic Status Panel — quick reference for relations
- Research Tree Overlay — visual aid for tech progression

### 🏛️ City Management
- City Planner Notes — layout templates for districts
- Citizen Assignment Helper — optimize worked tiles
- Building Queue Notes — organize construction order
- Trade Route Planner — map out trade paths
